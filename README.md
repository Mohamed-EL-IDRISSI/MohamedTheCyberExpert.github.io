# 🛡️ Cybersecurity Engineering Portfolio

A modern, high-performance personal portfolio website built for a **5th-Year Cybersecurity Engineering Student**. Features an interactive CLI terminal hero, responsive Bento Grid layout, CVSS-tagged research showcase, interactive writeup modals, and a built-in PGP key handler.

## ✨ Features

- **Interactive CLI/Terminal Hero Section**: Simulated interactive terminal supporting commands (`whoami`, `skills`, `ctf`, `projects`, `certs`, `clear`, `contact`).
- **Bento Grid Layout**: High-scannability grid showcasing core stack, homelab architecture, certifications, and academic degree milestones.
- **Vulnerability & CTF Showcase**: Interactive research cards with official CVSS v3.1 severity color coding and detailed writeup modals.
- **PGP Key Drawer**: Encrypted contact modal with single-click key copying functionality.
- **Responsive Dark Theme Design**: Built with Tailwind CSS, custom glow utilities, backdrop blurs, and emerald/cyan high-contrast accents.
